# دراسات الشركات — Vercel

مساحة عربية خاصة لمقارنة أداء الشركات بمصادر واضحة وحسابات حتمية. هذه النسخة تستخدم Next.js على Vercel؛ نسخة Sites المنشورة سابقًا مستقلة ولم تُعدّل أثناء هذا النقل.

## النشر

- Node.js 22، مدير الحزم pnpm المثبت في package.json.
- Framework Preset: Next.js، أمر البناء `pnpm build`، مجلد الإخراج الافتراضي لـ Next.js (بدون override).
- شغّل Vercel Authentication على **All Deployments** قبل السماح بالحفظ. لا تعطّل الحماية أو تضف استثناءات لمسارات API.
- هذه مساحة واحدة مشتركة للمصرح لهم من فريق Vercel أو من تمنحهم رابط مشاركة. ليست نظام حسابات عامة ولا تعزل بيانات أعضاء الفريق عن بعضهم.
- الطلبات الإنتاجية مقيدة بروابط Vercel المعروفة. النطاق المخصص يحتاج نظام تسجيل دخول مستقل قبل تفعيله.

## خطوة تفعيل التخزين

من مشروع **drast** في Vercel: Storage → Create Database → Blob → **Private** → Connect Project → اختر drast وبيئتي Production وPreview ثم أعد النشر.

اسم مقترح: `drast-private-reports`. الربط الحديث يضيف `BLOB_STORE_ID` مع صلاحيات OIDC؛ يدعم الكود أيضًا `BLOB_READ_WRITE_TOKEN` إذا كان الربط يستخدم رمزًا ثابتًا. لا تضع أي رمز في المستودع أو المتصفح.

حتى ربط المخزن، يعرض الموقع الدراسات الأولية مع تنبيه واضح، ويعطّل أزرار الحفظ والاستيراد والرفع. لا يدعي حفظ البيانات ولا يستخدم القرص المؤقت كبديل دائم. بعد الربط، تحفظ الدراسات وبيانات التقارير في JSON خاص؛ تقارير PDF الأصلية ترفع مباشرة إلى Blob، حتى 15 ميجابايت، لتجاوز حد جسم الطلب في دوال Vercel. النص المستخرج محدود بـ3 ميجابايت و300 صفحة. القراءة والتنزيل يمران عبر المساحة المحمية. الملفات الأصلية والنصوص ليست عامة.

كل دراسة تحفظ في سجل مستقل لتجنب فقدان سجلات دراسات أخرى عند تزامن الحفظ. تحديث الدراسة نفسها يتبع آخر حفظ. التخزين مناسب لحجم مساحة البحث الحالية، مع حد عرض 1000 سجل لكل نوع؛ تجاوز الحد يظهر خطأ صريحًا ولا يخفي السجلات بصمت.

## العمل مع الوكيل

الوكيل هو محادثة ChatGPT، وليس نموذجًا مستضافًا داخل التطبيق. أرفق التقارير بالمحادثة واطلب دراسة، مع ملف JSON مصدّر كمرجع للبنية، ثم استورد المسودة إلى المنصة. يمكن لأداة MCP على `/mcp` قراءة السجلات وحفظ مسودات عند ربط عميل مصرح له بحماية Vercel. إضافة Sites السابقة مرتبطة بموقعها وببياناتها المستقلة؛ لا تنقل الربط أو الملفات تلقائيًا إلى هذه النسخة.

الرفع وحده لا يطلق تحليلًا لغويًا أو بحثًا مجدولًا. لا توجد مفاتيح نموذج مضمنة.

## الحسابات والمصادر

محرك `lib/study-engine.mjs` لم يتغير. القيم بمليون ريال؛ المفقود يبقى غير متاح؛ لا يُحسب النمو من أساس صفري أو سالب؛ ولا تُطرح أرصدة الميزانية لاشتقاق ربع. الدراسات مسودات وتحتاج مطابقة الأرقام بالمصادر الأصلية. الربع الثالث للحبيب قيد التحقق؛ دراسته مبدئية.

## التحقق والتطوير

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

اختبارات المحرك والحفظ والصلاحيات في `test/`. اختبارات التخزين تستخدم مخزنًا معزولًا داخل الاختبار؛ لا تثبت ربط مخزن الإنتاج. التحقق الحي من حفظ تقرير وتنزيله مطلوب بعد ربط المخزن.

ملفات إعداد Sites/Cloudflare القديمة باقية مرجعية؛ لا يستوردها مسار بناء Next.js أو مسارات API في هذه النسخة.
