# دراسات الشركات — تجربة الأبحاث الخاصة

منصة عربية على Next.js / Vercel لجمع مصادر الشركات، إدارة مهام الأبحاث، تحرير المسودات ومقارنتها. المشروع `drast` مستقل عن أي مشروع آخر: لا مفاتيح أو قواعد بيانات أو واجهات لمشروع Badeeha، ولا ربط ببيانات نسخة Sites القديمة.

## النسخة الحالية

- مكتب أبحاث بطابور يدوي واقتراحات يومية لشركتين أو ثلاث، وسجل يساعد على تدوير قائمة المتابعة: الحبيب، أرامكو، سابك، stc، المراعي، بان القابضة، كافد وHUMAIN.
- جمع محدود عند الطلب من نطاقات علاقات المستثمرين الرسمية. تظهر الوثائق المقروءة، الصفحات، الاقتطاع وتعذر الوصول. ليس اشتراك أخبار شاملًا ولا موصل تداول مرخصًا.
- حفظ مهام البحث والأدلة والمسودات والتعديلات في **IndexedDB داخل المتصفح**. لا تحتاج هذه الوظائف إلى قاعدة بيانات أو تسجيل دخول داخل التطبيق.
- تصدير واستيراد نسخة JSON احتياطية، وتصدير التقرير نصيًا/JSON والطباعة إلى PDF. الحفظ محلي لكل متصفح؛ لا مزامنة أجهزة أو مشاركة فريق. مسح بيانات المتصفح يمحو السجلات، لذا صدّر نسخة احتياطية.
- الطابور يعمل أثناء فتح الصفحة؛ إغلاقها يوقف التنفيذ بعد آخر مرحلة محفوظة. استأنف من السجل. لا توجد جدولة خادم تعمل يوميًا أثناء إغلاق الموقع.
- لا يُستبدل تعديل المحلل بصمت. المهمة الجديدة تنشئ نسخة مستقلة، وتطابق السؤال والنطاق وبصمة الأدلة يمنع تكرار الصياغة إلا بطلب نسخة جديدة.

## الفهرس والملفات الاستراتيجية

يحتوي فهرس الهوية على 376 اسمًا ورمزًا من جداول تداول الرسمية (253 الرئيسية و123 نمو)، وفق لقطة قراءة 3 نوفمبر 2026؛ لا يثبت اكتمال تغييرات الإدراج أو الأسماء حتى ذلك اليوم. الأسماء الإنجليزية محفوظة كما في المرجع، وأضيفت مرادفات بحث عربية مختارة لـ92 شركة، وهي ليست أسماء قانونية بديلة. لا يحتوي الفهرس أسعارًا أو موصلات تلقائية لـ376 شركة؛ الجمع المهيأ مقيد بجهات البداية الثماني فقط.

كافد وHUMAIN ملفان استراتيجيان منفصلان عن محرك أرباع الشركات المدرجة. المصادر تربط الرؤية والأهداف والتمويل وحالات التنفيذ دون اختلاق أرباح أو نسب إشغال أو معاملة التمويل كإيراد. تحليل الحدث/الاستراتيجية متاح لهما ضمن نطاق المصادر المعتمدة؛ لا يقبل الخادم طلب نتائج مالية مدرجة لهما. دراستهما الثابتة مبدئية ومؤرخة ويمكن الرجوع إلى إسناداتها؛ لا تُعتبر ثمرة تشغيل AI الحي الذي ينتظر المفتاح.

## تفعيل AI المجاني

أنشئ مفتاحًا مخصصًا لهذا المشروع من OpenRouter، ثم أضف **OPENROUTER_API_KEY** في إعدادات Environment Variables لمشروع **drast فقط** في Vercel وأعد النشر. لا تضع المفتاح في Git أو المتصفح أو المحادثة، ولا تستخدم مفتاح مشروع آخر. لا حاجة إلى مفتاح Google AI Studio.

المسار الافتراضي `openrouter/free`. اختياريًا اضبط `DRAST_FREE_MODEL` على معرّف نموذج متاح ينتهي بـ `:free`. لا يضمن الكود توفر نموذج Qwen مجاني بعينه. يرسل الخادم سقف سعر صفرًا للإدخال والإخراج والطلب، دون أدوات ويب مدفوعة أو تحويل إلى نموذج مدفوع، ودون إعادة محاولات آلية. نفاد الحصة أو غياب مزود مناسب يظهر خطأ ويحفظ المصادر لاستئناف الصياغة لاحقًا. المفتاح المنفصل لا يفصل حصص حساب OpenRouter المشتركة؛ لا تستخدم حسابًا تعتمد عليه تطبيقات أخرى إذا أردت فصل الحصة أيضًا.

المحتوى المرسل للنموذج هو نصوص المصادر العامة في المهمة وسؤال المستخدم. لا تُرسل التقارير الخاصة المرفوعة القديمة تلقائيًا إلى OpenRouter. راجع سياسة مزود النموذج قبل إضافة معلومات خاصة إلى سؤال البحث.

**دون مفتاح**، تُنتج المنصة حصر مصادر وفجوات فقط، مع تسمية صريحة. لا يُحسب ذلك دراسة مالية مكتملة. حتى عند تفعيل النموذج، الناتج مسودة تحتاج مراجعة بشرية؛ التحقق من الاستشهادات والبنية ووجود الرقم لا يثبت صحة فهم الفترة أو الوحدة أو الجدول.

## الأدوار وحدودها

المسار الحالي منظم بأدوار برمجية: منسق يقيد الشركة والسؤال والنطاق، جامع يجلب من نطاقات معتمدة، محرك حسابات حتمي، محلل لغوي بمفتاح المشروع فقط، فحص بنية وإسناد وأرقام، ومحرر بشري. ليست هناك مجموعة نماذج مستقلة تعمل في الخلفية طوال اليوم؛ النموذج اللغوي يستدعى عند صياغة المسودة بعد توفر الأدلة. لا يمتلك أدوات تصفح أو تداول أو صلاحية كتابة الأرقام في محرك المقارنة.

## الحسابات وجودة الأدلة

محرك `lib/study-engine.mjs` مستقل ولم يتغير: الحسابات حتمية، المفقود لا يصبح صفرًا، ولا تُطرح أرصدة الميزانية لاشتقاق ربع. لا يكتب نموذج اللغة الأرقام تلقائيًا في محرك المقارنة. الحبيب يحتفظ بمسودته المبدئية، وأضيفت دراسة مبدئية لبان القابضة (1820) بأرقام من القوائم الربعية والسنوية ومراجعها وصفحاتها؛ الشركات الأربع الأخرى ملفات متابعة فارغة من الأرقام حتى التحقق، وليست دراسات جاهزة.

التقرير يميز الحقائق وتفسير الإدارة والتحليل والسيناريو. المراجع المجهولة والأرقام غير الموجودة في أدلة الإسناد تمنع قبول مسودة النموذج؛ هذه حواجز أولية وليست اعتمادًا محاسبيًا. الدليل المرسل من المتصفح ليس توقيعًا يثبت صحة المحتوى الأصلي. يُراجع المحلل الرابط الأصلي والصفحة والفترة والوحدة قبل الاعتماد.

الجمع يقيّد HTTPS والنطاقات الرسمية، ويفحص التحويلات، ويحد حجم التنزيل وعدد الوثائق والصفحات والنص والوقت. المستند الممسوح ضوئيًا يحتاج OCR خارج هذه التجربة. القراءة قد تتوقف قبل الجداول المتأخرة؛ القيود تظهر في التقرير.

## جهات الأبحاث

تتضمن مكتبة المصادر دليل روابط لجدوى الاستثمار والراجحي المالية والرياض المالية من مواقعها الرسمية، مع تمييز الرأي التحليلي عن إفصاح الشركة. الدليل ليس موصل أخبار أو متابعة تلقائية أو اشتراكًا في بحوث محجوبة؛ بعض أحدث تقارير الرياض المالية يتطلب دخولًا لدى الجهة. الربط الآلي المستقبلي يحتاج التحقق من واجهة المصدر وشروط استعماله.

## الخصوصية والنشر

- Node.js 22، pnpm المثبت في `package.json`، Framework Preset: Next.js، `pnpm build`، ومجلد إخراج Next.js الافتراضي دون override.
- أبقِ **Vercel Authentication / All Deployments** مفعّلًا. عدم وجود دخول داخل التطبيق لا يجعل الرابط عامًا.
- مساحة واحدة للمصرح لهم عبر حماية الاستضافة؛ ليست صلاحيات مستخدمين/عملاء متعددة. الطلبات الإنتاجية مقيدة بروابط Vercel المعروفة. لا تفعّل نطاقًا مخصصًا قبل مراجعة سياسة الوصول.
- مسارات `/api/research/status` و`collect` و`draft` محمية، وطلبات الكتابة تتحقق من Origin. مفاتيح النماذج على الخادم فقط.
- رفع الملفات وحفظ بيانات المقارنة في الخادم وظائف قديمة اختيارية تعتمد على Blob خاص؛ تظل معطلة دون تهيئته ولا تمنع عمل مكتب الأبحاث المحلي. لا يلزم إنشاؤه للتجربة الحالية.

يمكن لاحقًا استبدال التخزين المحلي بمشروع Supabase **مستقل** للمهام والأدلة وإصدارات التقارير، مع عامل وجدولة ومزامنة وصلاحيات. لم تُنشأ قاعدة أو خدمة مدفوعة في هذه التجربة.

## التطوير والتحقق

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

اختبارات المحرك والصلاحيات والتخزين القديم وحدود موصل المصادر وعقد التقرير وقيد النماذج المجانية في `test/`. اختبار SDK يستخدم استجابة معزولة ولا يثبت تشغيل نموذج حي. التحقق الحي من AI يحتاج المفتاح المخصص وحصة مزود متاحة.

ملفات Sites/Cloudflare القديمة باقية مرجعية؛ لا يستوردها بناء Next.js أو ربط الأبحاث الجديد.
