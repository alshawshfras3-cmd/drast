# هوية دراسات المالية — الإصدار الأول

اسم المنتج المعتمد: **دراسات**. هوية مستقلة للبحث المالي ومقارنة أداء الشركات؛ ليست امتدادًا لهوية أي منتج آخر.

## الفكرة

المعلومة تُقرأ بالحبر، ويُستخدم اللون لتحديد الفعل والدلالة. الورق الأبيض هو السطح الأساسي، والرمادي الهادئ يفصل المناطق. البنفسجي توقيع محدود في العلامة والإجراء الأساسي والاختيار. لا يُلوّن النص التحليلي بالبنفسجي.

الرمز الأصلي مبني على حرف **د** مفتوح يحتضن ثلاثة صفوف بيانات. مساره الخارجي الحاد ثم المنحني يوحي بالانتقال من السجل إلى الفهم، والفتحة تحفظ خفة الرمز. لا نجمة ذكاء اصطناعي، ولا أعمدة نمو توحي بوعد استثماري.

## الأصول

| الملف | الاستخدام |
| --- | --- |
| `public/brand/drast-mark.svg` | الرمز المستقل؛ واجهات التطبيق والأيقونات |
| `public/brand/drast-lockup.svg` | الرمز والاسم العربي بمسارات متجهية ثابتة |
| `app/brand.css` | طبقة هوية نهائية محايدة للمكونات الحالية |

الـlockup لا يحتاج إلى تنزيل خط لعرض الاسم؛ حُوّلت كلمة «دراسات» من IBM Plex Sans Arabic وزن 600 المثبت في المشروع إلى مسارات. ملفات الخط الأصلية وترخيصها موجودة في `public/fonts/`.

لا تمدد الشعار، ولا تضف ظلًا أو تدرجًا لونيًا، ولا تفصل زخرفة جديدة عن الرمز. استخدم خلفية بيضاء أو رمادية فاتحة. الحد الأدنى المقترح: الرمز 24×24 بكسل، والـlockup عرض 160 بكسل. مساحة حماية حول الأصل تعادل 8 وحدات من شبكة الرمز ذي 64 وحدة.

### تباين النص على الأبيض

حُسبت النسب محليًا بمعادلة الإضاءة النسبية وتباين WCAG؛ ليست اعتمادًا رسميًا للتطبيق كله.

| اللون | النسبة إلى الأبيض |
| --- | --- |
| `#17212B` | 16.29:1 |
| `#344250` | 10.29:1 |
| `#536170` | 6.34:1 |
| `#5637B8` | 7.97:1 |
| `#087F5B` | 5.00:1 |
| `#B4233A` | 6.48:1 |
| `#805511` | 6.51:1 |

تظل علامة السالب/الموجب والتسمية موجودة مع اللون. القيمة المالية المحايدة تُعرض بالحبر، ولا تصبح خضراء لمجرد أنها كبيرة. خطوط الرسم emerald؛ النقاط والقيم السالبة red، وخط الصفر رمادي مميز.

## الخط والمقاسات

الخط: **IBM Plex Sans Arabic** المحلي، دون مصدر خارجي. الأوزان: 400 للنص، 500 لعناصر الواجهة، 600 للعناوين والأرقام المهمة. يُستخدم 700 عند الضرورة وباقتصاد.

| العنصر | المقاس المستهدف |
| --- | --- |
| متن الصفحة والتقرير | 15px، وتباعد أسطر 1.85–2 |
| بيانات الجدول ورؤوسه | 14px |
| تواريخ وميتا وملاحظات مساندة | 12px كحد أدنى |
| الإجراء الأساسي | 14px |
| عنوان البطاقة | 17–21px حسب المساحة |
| العنوان الرئيسي | 32–42px حسب العرض |

للأرقام `font-variant-numeric: tabular-nums`. محاور SVG حجمها 16px والقيم المهمة 17px داخل `viewBox`؛ يحافظ حد عرض 560px للرسم على نحو 12px فعليًا عند المساحات الضيقة، ويتيح التمرير الأفقي بدل تصغير البيانات حتى تختفي.

## تطبيق CSS

استورد `app/brand.css` **بعد جميع ملفات CSS للمكونات**، بما فيها `globals.css` و`research.css` و`entity-directory.css`. الطبقة تُبقي التخطيط ومسارات العمل والمحتوى كما هي، وتعيد ضبط الألوان والخطوط وحالات الاختيار فقط. لا تتطلب اعتماديات جديدة.

- الهيرو أبيض رسمي بحد علوي بنفسجي رفيع.
- رسم المستندات يبقى أصلًا توضيحيًا؛ أسطح رمادية وخط بيانات emerald، دون نجوم أو مساحة أرجوانية كبيرة.
- بطاقات الشركات والإحصاءات بيضاء بحدود محايدة؛ الأيقونات داخل خلفيات رمادية أو خضراء دلالية صغيرة.
- اختيار الشركة أو المهمة يظهر بخلفية خفيفة وحد/شريط محدود، لا لوحة بنفسجية كاملة.
- الإخراج المطبوع يستخدم الحبر والورق، مع حفظ فصل العناوين والأدلة.

## حدود التغيير والتحقق

الأصول وهذه الطبقة لا تغير الحسابات أو البيانات أو مزود النموذج أو API. الشعار صالح XML، وحدود كلمة العلامة فُحصت داخل مساحة الرسم. يبقى اختبار المتصفح على سطح المكتب والجوال مطلوبًا للتحقق من ترتيب استيراد CSS ومن عدم قص النصوص بعد زيادة المقاسات، خصوصًا بطاقات الفهرس وعناوين المصادر ومحاور الرسوم.
